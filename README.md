# Distributed Systems Coursework

## Overview

- **Part 1 – Sequential MapReduce:** Implementation of the `map_phase` and `reduce_phase` functions.
- **Part 2 – Distributed MapReduce:** Implementation of the Master and Worker modules to coordinate and execute distributed MapReduce tasks.

## Project Structure

| File | Description |
|---|---|
| `mrseq.ex` | Sequential MapReduce implementation |
| `master.ex` | Master process implementation |
| `worker.ex` | Worker process implementation |
| `mr_job.ex` | Provided MapReduce job module |
| `word_count.ex` | Provided word count example |
| `indexer.ex` | Provided inverted index example |
